# odin-recipes
Project Description 

A website displaying recipes each webpage has the following layout:
    - A link to the launch page(index.html)
    - Heading for the name of the recipe
    - Image of the finished product 
    - A description of the recipe actually makes
    - Ingredients required to male the finished product
    - Steps describing how to make the product

There Files ,Macaroni_and_cheese.html, Apple_Pie_Cookie.html and pork_chop_sandwich.html all have the same structure that was mention above

Index.html basically acts like an access point to see all the recipes and their respective steps and ingredients

This Project basically taught me how to create a simple web page using headings and paragraphs elements and make them more interesting by adding images to the web pages the link the pages together using relative links and that help me differentiate how absolute links and relative links both work using the anchor element
